# Алёна Соловова — конструктор-технолог

Сайт-визитка (одностраничный лендинг) для выхода в аутсорс: обо мне, услуги,
портфолио, контакты. Чистая статика — HTML/CSS/JS без сборки.

## Локальный просмотр

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

## Деплой на GitHub Pages

1. Создать репозиторий и запушить содержимое этой папки.
2. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`.
3. Сайт откроется по адресу `https://<username>.github.io/<repo>/`.

## Структура

```
index.html                 разметка секций
assets/css/styles.css       палитра, чертёжная сетка, адаптив, анимации
assets/js/main.js           прошивающая строчка, reveal, курсор-игла, портфолио
assets/js/portfolio-data.js список работ портфолио (генерирует build_portfolio.py)
assets/img/works/           сжатые фото работ (генерирует build_portfolio.py)
assets/img/portfolio/       эскизы (sketch-01..21.jpg), используются в «Услугах»
рисунки/                    исходные фото эскизов (не публикуются напрямую)
портфолио/<NN-работа>/      исходники портфолио: info.txt + фото (лекало*.jpg — лекала)
```

## Портфолио

Одна работа = папка `портфолио/<NN-название-латиницей>/` с `info.txt` (категория,
название, описание, материал, размер, что сделано, для кого) и фото. Файлы, чьё имя
начинается с «лекало», идут в слайдер «лекало ↔ изделие», остальные — фото изделия
(первое по имени — обложка). После изменений:

```bash
python build_portfolio.py
```
